ruff ASYNC119 yield-in-context-manager-in-async-generator

Every trigger kept its team context open across yield

FtBaseTrigger.run() is an async generator. It set the team ContextVar, then yielded events inside the with block. An async generator runs in its caller’s context, so every yield returned control to Airflow’s triggerer with the team still set. When the triggerer later closed the generator from a different context, reset() rejected the token.
